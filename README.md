# 💪 아린 헬스장

출석·회비 관리 웹사이트입니다. 파일 두 개로 돌아가고, 설치할 것이 없습니다.

## 사이트

| 사이트 | 파일 | 비밀번호 |
|---|---|---|
| 대기 화면 (출석) | `index.html` | `0220` `0304` `0511` (출석) · `0630` (달력 보기) |
| 관리자 모드 | `admin.html` | `0630@@` |

## 하는 일

- **출석** — 회원 비밀번호를 누르면 1회 1,000원이 빠지고 달력에 표시됩니다. 돈이 없으면 "삐이익" 소리가 납니다.
- **회원** — 0220 🦁 사자 / 0304 🐷 돼지 / 0511 🐰 토끼. 카드를 한 번 누르면 그 회원 달력만, 두 번 누르면 크게 보입니다.
- **달력** — 세 회원의 출석을 한 달력에서 같이 봅니다.
- **돈 넣기** — 관리자 모드에서만 할 수 있고, 비밀번호를 쓴 회원에게만 들어갑니다.
- **사물함** — A부터 U까지 21칸. 네모를 두 번 누르면 이름을 저장합니다.
- **운동 타이머** — 시간이 다 되면 "띠리링" 알람이 크게 울립니다.

## 저장

기록은 서버가 아니라 **그 브라우저 안에만** 저장됩니다(localStorage). 두 사이트는 같은 기록을 같이 씁니다.
